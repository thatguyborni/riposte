# Riposte on phones

This folder is the installable phone version of Riposte, served by GitHub Pages.
It is built by `build.sh`; don't edit `index.html` or `sw.js` by hand.

Open the page on a phone, then:
- **Android (Chrome):** menu → *Install app* (or *Add to Home screen*).
- **iPhone / iPad (Safari):** Share → *Add to Home Screen*.

It then opens full screen from its own icon, works offline, and picks up new versions by itself.
